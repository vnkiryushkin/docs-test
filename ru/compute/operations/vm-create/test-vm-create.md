# Создание виртуальной машины

В этой инструкции описываеться как создать и настроить виртуальную машину в облачной платформе Yandex Cloud. 

## Предварительные требавания

Штобы начать работу вам понадобится:

- Акаунт в Yandex Cloud
- Устоновленный Command Line Interface (CLI)
- Минимум 4 гигабайта свободных средств на щёте

## Порядок действий

1. Заходим в консоль управления и переходим в раздел «Compute Cloud.

2. Нажымаем кнопку "Создать ВМ" и указываем следующие парметры:
   - Имя машины (например webserver-1)
   - Зону доступности
   - Операционую систему (Ubuntu 20.04)
   - Обьем жесткого диска

3. В следующем окне выбераем конфигурацию:
   * 2 процессорных ядра
   * 4 гб оперативной памяти
   * Прикрепляем SSD-диск на 30 гб

4. После создания машины небходимо:
   - Добавте SSH-ключ для доступа
   - Настроить правила фаервола
   - Устоновить необходимые пакеты

## Подключение к машине

Что бы подключиться к созданной ВМ выполните следующую команду:
bash
ssh ubuntu@<ip-адрес>
При первом подключении система спросит добавить ли отпечаток ключа - введите "yes".

## Дополнительные настройки

После подключения желательно сделать следующие настройки

1. Обновить систему:
```bash
sudo apt update && sudo apt upgrate -y
```

1. Настроить временную зону
```bash
sudo timedatectl set-timezone Europe/Moscow
```

1. Создать группу для пользователей что будут работать с машиной:
```bash
sudo groupadd vm-users
```

## Возможные проблеммы

Если возникли сложности проверте:

- Достаточьно ли средств на балансе
- Правельно ли настроены правила фаервола
- Есть ли доступ к нужным портам
